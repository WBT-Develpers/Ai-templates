# ACTISMART Templates

64 standalone marketing templates across 10 trade niches.

Every template is a **self-contained folder**: one HTML file plus its own `images/`,
`video/` and `logos/`. Download a folder, open the HTML inside it, and it works. No build
step, no server, no shared asset library.

## Browse them

Open [index.html](index.html), or once GitHub Pages is enabled:
https://wbt-develpers.github.io/Ai-templates/

## Layout

```
templates/
  01-solar/
    solar-template-1/
      solar-template-1.html
      images/  video/  logos/
    solar-template-2/  ...
  02-electrical/  ...
```

Boiler carries ten templates, so its folders are zero-padded
(`boiler-template-01` ... `boiler-template-10`) to keep them in numeric order.

## Note

The `standalone/` folder and the two loose HTML files at the root are an earlier upload
from August. They are superseded by `templates/` and kept only for reference.

All contact details, addresses and company names in these templates are demonstration
placeholders. Phone numbers use the Ofcom reserved fictional range.
